# Python_project
Math Challenge project
It`s a maths quiz built in Python. 
The game generates 10 random math questions (addition, subtraction, and multiplication), tracks the score, times how long they take, and displays a final percentage correct.

Random problems are generated using the random module, combining two numbers (between configurable min/max values) with a randomly chosen operator.

The player is asked to solve each problem via the console.

The game tracks how many problems were answered correctly and calculates a final score as a percentage.

The time module records how long the player took to complete all problems.
